# Healthcare Appointment & Operations Dashboard

## 📊 Project Overview

An interactive healthcare analytics dashboard developed to analyze appointment activity, revenue, cancellations, wait times, locations, departments, and doctor performance.

The dashboard provides a clear view of healthcare operations and helps identify patterns and performance across departments, locations, appointment statuses, and doctors.

## 🛠️ Tools & Technologies

- Power BI
- SQL Server
- SQL
- DAX
- Power Query

## 📌 Key KPIs

- Total Appointments
- Cancelled Appointments
- Total Revenue
- Cancellation Rate
- No-Show Rate
- Average Wait Time

## 📈 Dashboard Analysis

The dashboard provides analysis of:

- Monthly appointment trends
- Monthly revenue trends
- Revenue by department
- Average wait time by department
- Appointments by location
- Appointment status
- Top 10 doctors by revenue

## 🔎 Key Features

- Interactive slicers for Year, Department, Location, Appointment Type, Appointment Status, and Month
- Clear Filters functionality
- Interactive Power BI visuals
- KPI cards for operational and financial metrics
- Department performance analysis
- Location analysis
- Doctor revenue ranking
- Monthly trend analysis

## 🧮 Data Analysis

SQL Server was used to query and analyze the healthcare data, including aggregation, filtering, grouping, and ranking analysis.

Power BI was used for data modeling, DAX calculations, Power Query transformations, interactive visualizations, and dashboard development.

## 💡 Project Objective

The objective of this project was to build an interactive analytics solution that provides healthcare management with an easy-to-understand view of operational and financial performance.

The dashboard helps users explore appointment trends, revenue performance, cancellation patterns, wait times, department performance, and doctor revenue.
